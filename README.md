# Крестики нолики
простая браузерная игра "Крестики нолики" на HTML, CSS и JavaScript.
## Запуск
Открой `index.html` в браузере и играй.
## Возможности
- поле 3x3
- два игрока добро (крестики) и зло (пентаграмки).
- проверка победы.
- определение ничьей.
- кнопка **restart**.
## Как запустить
1. Скачатть или склонировать репозиторий.
2. убедится в том что все лежит в одной папке.
3. открыть `index.html` в любом современном браузере.
